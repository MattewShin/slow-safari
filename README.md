# 느린 초원 · Slow Safari

힐링을 위한 로우폴리 3D 초원. 모바일 세로 화면을 우선 지원하는 정적 웹앱입니다.

## 첫 버전

- 가입 없이 기린·얼룩말·가젤·토끼·다람쥐 중 무작위로 탄생
- 풀밭 한 번 터치·클릭으로 걷기, 같은 곳 두 번 터치·클릭으로 달리기, WASD/방향키 이동, 배경 드래그로 상하좌우 시점 회전
- 15초간 조작이 없으면 자동으로 넓게 바라보기, 조작하면 저장된 시점으로 복귀 (동물의 행동 유지)
- 짧은 터치는 이동, 드래그는 시점 회전으로 구분. 시점 패널 없이 배경 드래그로 상하좌우 시점 조작, 모바일 핀치·마우스 휠로 거리 조절
- 한국 시각 06:00~18:00 낮, 그 외에는 별과 반딧불이가 보이는 밤
- 큰 호수에서 남쪽 끝까지 이어지는 강과 통나무 다리 네 곳, 고인돌과 매머드 골격
- 14종 중 무작위로 태어나며 초원 곳곳에서 다른 동물을 만날 수 있음
- 자연 소리를 켜면 낮의 새소리와 밤의 풀벌레·물가 소리, 2분 30초~6분 간격으로 약 27초의 오리지널 피아노 선율
- 이동 범위 200×200, 작은 연못 4곳과 숲·바위 군집 추가, 북쪽의 큰 호수(38×26)와 약 13m 높이 폭포·움직이는 물줄기와 물보라
- 호수와 절벽 진입 차단, 확장된 지도의 물가 자동 경로, 서쪽 호숫가 산책길
- 제자리에서 풀 뜯기(고개 숙이기·씹기), 쉬어가기, 현재 위치에서 가까운 호수·연못의 접근 가능한 물가로 자동 이동 후 물을 향해 물 마시기
- 선택적으로 켜는 합성 자연 소리, 가벼운 화면 모드
- 다섯 동물의 체형·눈 하이라이트·귀 안쪽·꼬리·표면 무늬 개선
- 관절 두 개로 다리를 굽히고 지면 높이에 발을 맞추는 걷기, 이동 거리에 맞춘 보폭
- 목 관절·턱 씹기·눈 깜빡임·귀·꼬리 움직임, 토끼 도약·착지와 다람쥐 앞발로 먹기
- 동물마다 하나의 스킨 메시로 부품을 묶어 모바일 그리기 부담 완화
- 작은 동물에 맞춘 가까운 시점, 휴식·풀 뜯기·물 마시기
- 나무 39그루를 세 군집(12/14/13그루)으로 추가해 작은 숲 조성, 줄기 충돌 처리
- 기존 동물 7마리와 토끼 6마리·다람쥐 4마리의 자동 이동 (온라인 멀티플레이 미포함)

`dist`를 정적 서버로 제공하면 실행됩니다. 외부 CDN, API 키, 계정, 데이터베이스가 필요하지 않습니다. 날씨 데이터는 [Open-Meteo](https://open-meteo.com/)에 연결합니다. 동물·지형·나무는 코드로 만든 메시이며 Three.js 라이선스는 `dist/vendor/THREE-LICENSE.txt`에 있습니다. WebGL 2 지원이 필요하며, 미지원 시 안내 화면을 표시합니다.

## 검증

JavaScript 구문 검사와 그래픽 렌더러를 대체한 실행 검증으로 장면 구성, 유한한 좌표, 다섯 종류 탄생, 이동, 휴식, 호수·연못의 가까운 물가 선택과 장애물 회피 경로, 시점 상하 회전·핀치·휠·거리 제한, 토끼와 다람쥐의 수·이동 범위, 작은 동물의 행동·시점, 나무 군집과 줄기 충돌, 호수·절벽 충돌과 확장 지도 경로, 폭포 애니메이션, 자동 바라보기 전환·복귀와 조작/대화상자/탭 숨김 처리, 다리 관절과 발 접지·턱·귀·눈·목·스킨 메시 좌표를 확인합니다. 확인용 클라우드 브라우저는 WebGL이 비활성화되어 있어 실제 3D 렌더링과 모바일 실기기 동작은 미검증입니다.
